A-Level Computer Science NEA (Grade: 57/70)

As part of my Computer Science A-Level, I designed and developed a desktop implementation of the class Solitaire card game using Python. The project was built entirely from scratch and followed a structured software development process, from analysing user requirements and designing the interface to implementing, testing, and evaluating the final application.,

The objective of the porject was to modernise the traditional Solitaire experiance by introducing features that improve user engagement while maintaining the core gameplay.

Key features of the application include:

  • User registration and login system with SQLite database.
  • Customisable game themes, card backs and card designs.
  • Multiple difficulty levels with reshuffle limits.
  • Interactive game interface built using Python.
  • Settings menu with music and sound effect controls.
  • In-game help and instructions for new players.
  • Timer, game statistics and additional gameplay features.
  • Input validation and error handling throughout the application.

My Approach

I designed the application using object-oriented programming principles to seperate the game's functionality into reuseable classes, making the code easier to maintain and extend. The interface combined Pygame for the game board with Tkinter for menus and dialog windows, allowing me to create a user-freindly desktop application.

Thoughout the development I adopted an iterative appraoch, implementing and testing each feature individually before integrating it into the complete system. This helped ensure the application remained reliable as new functionality was added.

Challenges

One of the biggest challenges I encountered was implementing the card movement mechanics. While I successfully developed the game's interface, user authentication, settings and other supporting features, I was unable to fully implement the interactive movement of cards within the time available. This highlighted the complexity managing the game state, vaildating moces and coordinating user interaction in a graphical application. Although the feature remained incomplete, the experiance improved my problem solving skills and gave me a greater appreciation for the importance of planning, incremental development and allocating sufficient time to technically demanding features.

Another challenge was integrating mutiple technologies within the same application. I used Pygame for the main interface while using Tkinter for features such as login, account creation and setting windows. Ensuring these components worked together smoothly required careful planning and debugging.

Software Engineering Coursework (Grade: 70.6/100)

As part of my second-year Software Engineering coursework, I collaborated in a seven-member team to design and develop NeighbourLink, a full-stack web application aimed at connecting local communities by enabling users to organise events, request assisstance, and report community issues. The project followed an Agile-inspired development process, with team members collaboarting though git using feature braches and pull requests to manage changes and ensure code quality.

The frontend was developed using HTML, CSS, and TypeScript, focusing on creating a resopnsive, intuitive, and accessible user interface. The backend was built with Node.js and Express.js, exposing RESTful APIs to handle client requests and business logic, while PostgreSQL was used as the relational database for sotring user accounts, events, reports and other application data. Throught the project, I gained valuable experaince in full-stack development, collaborative software engineering practices, version control, and building scalable, web applications.

My role

I was primarily responsible for the overall frontend design and implementation. My resposibilities included:

  • Designing the user interface structure and page layouts.
  • Creating reusable frontend components to maintain consistency.
  • Implementing dark mode functionality.
  • Developing navigating between different sections of the application.
  • Creating the report feature.
  • Reviewing and integrating team members' changes.
