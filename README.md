# Portfolio
My personal portfolio website.

## Overview:
This repository contains my personal portfolio website, developed to showcase my academic journey, technical skills, projects and experience as a Computer Science Student.

This website was created using HTML, CSS and JavaScript. The aim of this first iteration was to develop a clear and functional portfolio with a simple structure, while applying the web development concepts I have developed throughout my degree.

## Features:
- Navigation bar linking to different sections of the website
- Personal introduction and education section
- Technical skills section
- Project showcase
- Interactive project walkthrough
- CV download functionality
- Contact section

## Technologies Used:
- HTML5: Used to structure the content and pages of the website.
- CSS3: Used for styling, layout, positioning and overall visual design.
- JavaScript: Used to add interactive functionality to the website.
- Git & GitHub: Used for version control and project management.
- Visual Studio Code: Used as the development environment.

## How to Run:
To view this website locally:
1. Clone this repository.
2. Open the project folder in Visual Studio code.
3. Open `index.html` by right clicking and pressing "Open with Live Server".
